# 订单金额与信息可用性

`order_cash_review` 汇总原订单金额并区分未收、部分收、足额收和超额需复核。允许多个已验证capture累计收款；超额不静默视为正常，也不自动退款。退款复核提示仍不是合同指令。退款后的业务义务、原始收款状态和批次结算状态需分别阅读。

`availability.reconcile_as_known` 是显式选择的日粒度接口，要求每条支付和银行记录提供 received_date。先按收到日期筛选，再按业务日期核对；重发仅因收到日期不同不会重复计款。假设同一本地日历，未支持时区、日内先后、真实节假日和预计结算日。同日物流事件仍按来源顺序，退货早于所引用发货会拒绝。

不连接生产支付。新增接口并未与FIFO或月度现金流架构合并。公开机构结算费率研究保留后续任务，避免未核实条款造成虚假精确。
